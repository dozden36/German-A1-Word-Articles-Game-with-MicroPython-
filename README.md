# German-A1-Word-Articles-Game-with-MicroPython-
A DIY language learning device built with an RP2040-Zero and a 0.96" IPS display to practice German A1 articles. Written in MicroPython, it displays random words and uses three buttons with RGB LED feedback for correct or wrong answers. You can edit the word list on the code.



DISPLAY    BOARD
SCL -------- GPIO 2
SDA -------- GPIO 3
RES -------- GPIO 5
DC  -------- GPIO 4
CS  -------- GPIO 1
BLK -------- GPIO 6


BUTTON   BOARD
DER ---- GPIO 14
DIE ---- GPIO 27
DAS ---- GPIO 26
